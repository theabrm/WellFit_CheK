This is not a program designed for production. It is a school project created to fulfill one of the requirements in Computer Programming 1.

# WellFit CheK
This system aims to replace the handwritten index cards used by the PATHFit professors for their student’s health and fitness evaluation on the university’s clinic. The system will automatically compute the necessary computations such as BMI, label the status of the student, and print the output on behalf of the university's nurse, in order for the student to pass the printed evaluation to his/her PATHFit professor.
